How to Import Transactions

  1. Download your bank statement as CSV from your bank's website
  2. Place the CSV file in your configured import folder (see config.yaml or set ABACUS_IMPORT_DIR)
  3. Or run manually: python3 src/import_csv.py path/to/file.csv
  4. Refresh this page to see the import appear in the history below

Note: Duplicate files and transactions are automatically detected and skipped.
